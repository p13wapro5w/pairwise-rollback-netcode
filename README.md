# pairwise-rollback-netcode

格斗游戏联机时，一方打出连招另一方画面已经倒地，回滚只回退了角色位置，没回退碰撞与受击状态；输入延迟固定 2 帧，但高延迟玩家实际超前 5 帧，判定在两边算出不同结果；状态哈希用浮点位置直接比较，微小误差每帧都判定失同步；随机数在客户端各自推进，暴击与硬直帧数对不上；回滚重放只重放了输入，没重放已销毁的投射物；断线重连后从服务器快照恢复，本地预测帧没清空，角色在两个位置之间闪；观战端按服务器帧插值，但没做回滚补偿，看到的结果总是慢一拍；帧优势计算把回滚帧算进等待时间，双方互相等；平台间浮点运算顺序不同，同一套回滚在 PC 与主机上结果不一致；回滚缓冲按固定 60 帧分配，长连招超过缓冲后旧状态被覆盖。gameplay/rollback_netcode.py 是核心，tests/test_rollback_netcode.py 15个红。要修的是：全状态回滚；按实际延迟调输入；定点哈希；确定性随机；投射物入回滚；重连清预测；观战补偿；帧优势不含回滚；定点物理；按最长连招分配缓冲。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
